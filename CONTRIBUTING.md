# Contributing / Contribuir

Thank you for your interest in RetroWorks Music Studio (RMS).  
Gracias por tu interés en RetroWorks Music Studio (RMS).

## English

### Before contributing
- Check existing issues and discussions before starting substantial work.
- For significant changes, open an issue first to discuss scope and design.
- Keep changes focused and explain the motivation.

### Development principles
- Prefer clear, maintainable C# code.
- Keep UI, domain logic, audio I/O, and DSP concerns separated.
- Avoid platform-specific assumptions in shared code.
- Add tests for DSP, parsing, serialization, and other deterministic logic.
- Document public APIs and non-obvious design decisions.

### Pull requests
- Use a concise, descriptive title.
- Explain what changed and why.
- Include tests or explain why they are not applicable.
- Update documentation when behavior or architecture changes.

## Español

### Antes de contribuir
- Revisa las incidencias y debates existentes antes de comenzar cambios importantes.
- Para modificaciones relevantes, abre primero una incidencia para acordar alcance y diseño.
- Mantén los cambios centrados y explica su motivación.

### Principios de desarrollo
- Prioriza código C# claro y mantenible.
- Separa interfaz, dominio, entrada/salida de audio y DSP.
- Evita dependencias de plataforma en el código compartido.
- Añade pruebas para DSP, análisis, serialización y lógica determinista.
- Documenta las API públicas y las decisiones de diseño menos evidentes.

### Pull requests
- Utiliza un título breve y descriptivo.
- Explica qué cambia y por qué.
- Incluye pruebas o indica por qué no proceden.
- Actualiza la documentación cuando cambie el comportamiento o la arquitectura.

## License / Licencia

By contributing, you agree that your contributions will be subject to the project's license once one is selected and added. Until then, please discuss contribution terms with the maintainers.  
Al contribuir, aceptas que tus aportaciones quedarán sujetas a la licencia del proyecto cuando se seleccione y añada. Mientras tanto, consulta las condiciones con las personas responsables del proyecto.
