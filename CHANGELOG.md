# Changelog

All notable project changes are documented here.  
Aquí se documentan los cambios relevantes del proyecto.

## [Unreleased]

### Changed
- Confirmed C++11 as the required language standard for the entire application, including the desktop interface.
- Replaced the provisional C#/.NET and Avalonia direction with a C++11, CMake-based modular architecture.
- Listed PortAudio and C++11-compatible UI and test frameworks as candidates pending evaluation.

## [0.1.0] — 2026-10-25

### Added
- Initial repository bootstrap.
- Bilingual README (English and Spanish).
- Project vision, provisional architecture, roadmap, contribution guide, and versioning policy.
- Initial .NET-oriented `.gitignore`.

### Notes
- No application executable or audio-analysis engine is included in this milestone.
- The initial technology direction has since been superseded by the C++11 decision.
- No software license has been selected yet.
